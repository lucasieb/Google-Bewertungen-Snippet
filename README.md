# Google-Bewertungen-Snippet
Ein Snippet in Form eines HTML-Codes, der im Hostinger Webbaukasten als "Code einfügen" eingesetzt wird. Es wird das Google Profil dargestellt und zusätzlich besteht die Option Beispielrezensionen anzeigen zu laseen. Dieses letzte Feature kann über true/false aktiviert oder deaktiviert werden. Das Snippet zeigt somit die Rezensionen im Google-Stil.
